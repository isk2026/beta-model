# Beta Model 대시보드

성상현 「매크로비욘드」 6-2부의 **베타 모델**(추세 점수 × 위험 점수 → 주식/현금 비중)을 구현한 개인 투자 참고용 도구.

```
beta_model/            Python 엔진
  config.py            모든 파라미터 (가중치·임계값·배분 공식)
  data_pipeline.py     1단계: 데이터 수집 + SMA/MDD/변동성/ROC
  scoring.py           2단계: BetaModelScoringEngine (추세 -1~+1, 위험 0~1)
  allocation.py        3단계: 비중·국면·속도조절·리밸런싱
  export.py            실행 → dashboard/public/data/beta_model.json
  backtest.py          1990~ 백테스트 + 워크포워드 → dashboard/public/data/backtest.json
tests/test_model.py    오프라인 단위 테스트 (합성 데이터)
dashboard/             4단계: React + Tailwind + Chart.js + lucide
```

## 실행

```bash
pip install -r requirements.txt
python -m beta_model.export --refresh   # 데이터 수집 + JSON 생성 (매일 장 마감 후)
python -m beta_model.backtest           # 장기 백테스트 리포트
python -m beta_model.backtest --grid    # 파라미터 그리드 (표본 내 선택 → 표본 외 확인)
python -m beta_model.validation         # 견고성 검증 (다른 나라·워크포워드·부트스트랩·민감도·비용) ~5분
python -m beta_model.experiments long-trend   # 채택 전 실험: 장기 추세 요소 (data/experiments/*.csv)
python -m beta_model.experiments vol-proxy    # 채택 전 실험: VKOSPI proxy keep/drop
python -m pytest -q                     # 테스트

cd dashboard
npm install
npm run dev                             # http://localhost:5173
```

## 원래 프롬프트 대비 변경점

| 항목 | 원 프롬프트 | 변경 | 이유 |
|---|---|---|---|
| 배분 공식 | Base = 0.80 + 0.20·trend | **Base = 0.85 + 0.15·trend** (70~100%) | 원 공식은 추세 −1이면 위험과 무관하게 60%가 되어 원문의 '하락 방어(과도한 현금화 지양)'와 '최대 방어(현금 40%)'가 구분되지 않음 |
| 국면 | 대시보드에만 표시 | Python/JS 공통 로직 (`classify_regime`) | 국면 기준을 한 곳에서 관리 |
| 속도 조절 | 없음 | 줄일 땐 즉시, 채울 땐 하루 +2%p, 종가 신호 → 익일 집행 | 원문 계좌 운용 원칙 2·3번 |
| 변동성 지수 | 252일 백분위 | 백분위 50% + 절대 레벨 50% | 조용한 1년 뒤에는 VIX 16도 상위 백분위가 됨 |
| 신용 위험 | HY 스프레드 Z점수 | **Baa−10Y** Z점수 50% + 절대 레벨(2.5%p→0, 4.5%p→1) 50% | FRED의 HY OAS는 최근 3년만 제공되어 검증 불가. Baa는 1986년부터 있어 백테스트=운영 일치 (HY는 참고로만 표시) |
| 금리·환율 | 10일 변화율 | 10일 **상승분만** 위험으로 반영 | 금리 하락·원화 강세는 위험이 아님 |
| 시장 | 단일 | 미국(S&P·나스닥+VIX) / 한국(코스피·코스닥+VKOSPI) 별도 | 원문이 미국·한국을 다른 국면으로 평가 |
| 지표 계산 | 공통 달력 ffill 후 계산 | 시장별 거래일 기준 계산 후 정렬·ffill | 휴장일 ffill이 변동성을 과소평가함 |
| 대시보드 | 슬라이더 시뮬레이터 | 실측 점수 + 시뮬레이터 + 구성요소 분해 + 1년 추이 + 국면 지도 | 투자 참고용으로 "왜 이 비중인지"가 보여야 함 |
| 데이터 추가 | — | 달러 인덱스(DXY) | 원문에서 위험 모니터링 지표로 언급 |
| 국면 판정 | 단일 임계값 | **이중 임계값(히스테리시스)**: 추세 ±0.10, 위험 ±0.05 | 경계 근처에서 국면이 매일 뒤바뀜(연 10~13회, 절반이 5일 이내) → 연 4~6회, 중앙 지속 20일+ |
| 한국 현금 | 원화 MMF | **원화 50% + 달러 50%** (달러 MMF·미 초단기국채) | 코스피 급락 때 원/달러 상승(상관 −0.21) → 최대낙폭 −40%→−35%, 수익 동일. 50% 이상은 개선이 멈추고 환 노출만 증가 |

## 검증 결과 (1990~ 미국 / 2001~ 한국)

`python -m beta_model.backtest` · 가정: 종가 신호 → 익일 집행 → 그다음 날 수익 반영, 비용 10bp, 현금 = 3개월 금리, 가격지수.

| 미국 SPX 1990~ | 연수익 | 최대낙폭 | 샤프 | 회전율/년 |
|---|---|---|---|---|
| 보유 그대로 | 8.6% | −56.8% | 0.40 | – |
| 고정 비중 83% (모델 평균과 동일) | 7.8% | −49.3% | 0.40 | 0% |
| 기존 모델 | 7.3% | −41.5% | 0.40 | 326% |
| **현재 모델** | 7.6% | −42.2% | 0.41 | **81%** |

| 한국 KOSPI 2001~ | 연수익 | 최대낙폭 | 샤프 | 회전율/년 |
|---|---|---|---|---|
| 보유 그대로 | 9.5% | −54.5% | 0.38 | – |
| 고정 비중 80% | 8.7% | −45.7% | 0.38 | 0% |
| 기존 모델 | 9.0% | −39.4% | 0.41 | 306% |
| **현재 모델** | 9.0% | −40.1% | 0.41 | **87%** |

- **결론:** 수익을 높이는 모델이 아니라 **큰 하락을 줄이는 모델**. 자동 추출한 최악 하락 6개 구간 모두에서 보유 그대로는 물론
  평균 비중이 같은 고정 포트폴리오보다 손실이 작았다(예: 2008년 −57% → −42%, 고정 −49%).
- **개선 효과:** 정배열 연속값(이격도 tanh, scale 0.04) + 추세 점수 10일 EMA + 집행 무시구간 3%p로
  회전율 320% → 80%대, 연 매매일 170일 → 35일. 샤프·최대낙폭은 유지.
- **파라미터 선택 방식:** 1990~2012(표본 내)에서 "샤프가 최고치와 0.01 이내인 조합 중 회전율 최저"를 고르고 2013~(표본 외)는 확인만 했다.
  24개 조합의 표본 외 샤프가 모두 0.526~0.537로 평평해서 특정 값에 과적합되지 않았다.
- **한계:** 공포 국면(4)은 이후 20일 수익이 가장 높은 구간이기도 하다(미국 +1.8%, 한국 +1.5%).
  "위험 점수가 꺾이면 위험 차감을 해제"하는 자동 규칙을 시험했지만 효과가 미미하고 회전율만 늘어 채택하지 않았다 → 수동 판단 영역.
- **국내 신용 스프레드(ECOS, AA− − 국고 3년)** 를 한국 위험 점수에 섞어 봤지만(0.9~1.8%p 구간) 표본 내 샤프 0.456→0.451,
  위험-향후낙폭 순위상관 −0.126→−0.115로 개선이 없어 채택하지 않았다(`kr_credit_blend = 0`). 글로벌 위기에서는 미국 Baa와 함께 움직이고,
  국내 고유 사건(2003 카드채, 2022 레고랜드)은 추세 점수가 이미 반영했기 때문으로 보인다. 매크로 패널에 참고 지표로 표시하고,
  ECOS CD 91일은 원화 현금 수익률로 사용한다.
- **한국 현금 50% 달러:** 표본 내(2001~2012)에서 0/25/50/75/100%를 비교해 최대낙폭 개선이 포화되는 50%를 고르고, 표본 외에서도
  같은 방향(−34.9%→−34.0%)임을 확인. 2026년 하락처럼 원화가 강했던 구간에서는 오히려 약간 불리했다(−30%→−32%).
- 미국 위험 점수의 예측력은 약하다(위험 상위 25%의 향후 20일 최저수익 −3.8% vs 하위 25% −1.7%). 한국은 더 뚜렷하다.

### 미국(기술) — QQQ·SOXX 가중 (1999~)

기술주 비중이 높은 포트폴리오용 세 번째 시장. 추세 점수 = QQQ·SOXX 각 추세 점수의 **포트 비중 가중평균**,
수익률·실현변동성은 같은 비중의 바스켓(매일 리밸런싱), 위험의 나머지(VIX·금리·환율·신용)는 미국과 공통.

- 비중 `QQQ 40% / SOXX 60%` (실제 포트 비율) — `beta_model/config.py`의 `MARKETS["US_TECH"]["index_weights"]`를 실제 비율로 수정
  (대시보드 '미국(기술)' 탭 슬라이더로도 바꿀 수 있지만 그건 브라우저 화면에만 반영, 기록·백테스트·알림은 config 기준).
- SOXX 상장(2001-07) 전에는 QQQ만으로 계산(남은 비중으로 재정규화).
- 파라미터 선택(그리드·워크포워드)에는 미국·한국만 쓰고, 미국(기술)은 **맞춰보지 않은 표본**으로 남겨 두었다.

| QQQ 40 / SOXX 60, 1999~ | 연수익 | 최대낙폭 | 샤프 | 회전율/년 |
|---|---|---|---|---|
| 보유 그대로 | 10.8% | −85.3% | 0.42 | – |
| 고정 비중 | 10.0% | −77.7% | 0.42 | 0% |
| **현재 모델** | 10.7% | −72.3% | 0.47 | 87% |

- 6개 최악 구간 중 5개에서 고정 비중보다 손실이 작았다(2022년 −42% → −32%, 고정 −35%). 짧고 빠른 2026-06 급락에서는 약간 컸다.
- **주의:** 주식 하한 60%라 닷컴 붕괴(−85%)급에서는 모델도 −72%까지 빠진다. 변동성이 큰 자산일수록 '최대 방어 60%'의 실제 손실이 크다.

### 주도 섹터 모니터 (참고용, `python -m beta_model.sectors`)

미국 섹터 ETF 11개(XLK·XLE·XLV…)를 상대강도 = (6개월 + 12개월(최근 1개월 제외) 수익률) ÷ 2 로 줄 세우고,
같은 추세 엔진으로 섹터별 추세 점수를 낸다. ★ 주도 = 상대강도 상위 중 추세 > 0, 200일선 위인 3개.
대시보드 미국·미국(기술) 탭에 순위, 12개월 순위 추이, QQQ·SOXX 상태를 표시한다.

**배분 규칙에는 넣지 않았다** (`python -m beta_model.sectors --backtest`):

| 주식 중 섹터 배분 규칙 (월 1회, 비용 10bp) | 표본 내 1999~2012 | 표본 외 2013~ |
|---|---|---|
| SPY 100% | 연 2.6% · 샤프 0.23 | **연 14.8% · 0.91** |
| 추세 비례 0~40% → 상위 2/3/4개 | 2.9~3.0% · 0.24~0.25 | 14.0~14.5% · 0.86~0.89 |
| 고정 40% → 상위 2/3/4개 | 3.4~3.9% · 0.27~0.29 | 13.7~14.1% · 0.86~0.89 |
| 100% 섹터 로테이션 상위 3개 | 5.5% · 0.36 | 12.3% · 0.76 |

2000년대에는 효과가 있었지만 2013년 이후에는 모든 변형이 SPY에 졌다 — 표본 내 결과로 채택했다면 과적합이었을 것.
기술주 포트(QQQ 40/SOXX 60)를 상대강도로 ±10~30%p 기울이는 규칙도 조회 기간(3/6/12개월)에 따라 결과가 뒤집혀 기각.

**한국** (`python -m beta_model.sectors --universe KR [--backtest]`): KOSPI200 섹터지수를 추종하는 TIGER 200 섹터 ETF 11개
(IT·금융·에너지화학·중공업·철강소재·건설·경기소비재 2011-04 상장, 헬스케어·산업재·생활소비재 2015-09, 커뮤니케이션서비스 2019-01),
기준 KODEX 200(069500), 보조 KODEX 반도체·2차전지. 모두 yfinance `.KS`(수정주가) — KRX 지수 원천(FDR `KRX-INDEX`, pykrx)은
KRX 로그인이 필요해 쓰지 않는다. 260거래일 미만 섹터는 순위에서 빠진다. 대시보드 한국 탭에 같은 형식으로 표시(`sectors_kr`).

| 한국 섹터 배분 규칙 (월 1회, 비용 10bp) | 표본 내 ~2018 (섹터 신호는 2012~) | 표본 외 2019~ |
|---|---|---|
| KODEX 200 100% | 연 3.8% · 샤프 0.32 | **연 19.6% · 0.76** |
| 추세 비례 0~40% → 상위 2/3/4개 | 3.7~3.9% · 0.32~0.33 | 16.4~17.2% · 0.67~0.69 |
| 고정 40% → 상위 2/3/4개 | 2.6~3.2% · 0.24~0.28 | 15.9~17.7% · 0.68~0.71 |
| 100% 섹터 로테이션 상위 3개 | 0.5% · 0.12 | 13.3% · 0.58 |

한국에서는 표본 내에서도 이득이 없었고 표본 외에서는 모두 졌다. 이력이 짧아 검증력은 제한적.

**옵트인 토글 '주도 섹터 위성 비중'** (대시보드 섹터 패널, 기본 꺼짐): 켜면 현재 주식 비중을 코어(SPY/지수 ETF)와
주도 섹터로 나눠 보여준다. 위성 = 주식 × 0.4 × clip(미국 추세, 0, 1), 주도 섹터 3개에 균등(3개 미만이면 남는 몫은 코어).
주식/현금 비중은 바뀌지 않으며, "검증상 근거 없음" 경고와 위 표본 내/외 수치를 함께 표시한다 (`sectors.satellite`).

## 위험 점수 개선: 시장 폭(breadth) 추가 (2026-10)

외부 벤치마크(ARIS 대시보드)의 지표들을 후보로, **향후 63거래일 안에 −10% 이상 낙폭이 올지**를 위험 점수가 얼마나 잘
구분하는지(AUC, 0.5 = 무작위)를 표본 내(~2012)·표본 외(2013~)로 나눠 측정했다.

| 후보 | 무료 장기 데이터 | 결과 |
|---|---|---|
| **시장 폭**: 동일가중(RSP) vs SPY 63일 + 200일선 아래 섹터 비율 | RSP 2003~, 섹터 ETF 1999~ | **채택** — 미국·한국, 표본 내·외 모두 AUC 상승 |
| HY CCC−BB 스프레드 | FRED는 최근 3년만 제공 | 검증 불가 → 매크로 패널 참고 지표로만 표시 |
| 신용 스프레드 추세 (Baa 20일 변화) | 1986~ | 단독 AUC 0.61/0.65지만 기존 신용 요소와 겹쳐 증분 없음 |
| 금리 커브 (2s10s, 3m10y, 10s30s) | 1985~ | 표본 내 0.46~0.49(무작위 이하) → 기각 |
| 유가 (63일 변화·백분위), 엔화 강세 | 1986~ | 0.44~0.52 → 기각 |
| VIX 기간구조(VIX/VIX3M), MOVE, SKEW, NFCI, HYG/IEF | 1990~2007~ | 표본 외에서 약해지거나 기존 점수에 섞으면 오히려 하락 → 기각 |
| SPX 옵션 GEX(감마 플립·콜/풋 월), 신용거래 잔고 | 무료 일별 이력 없음(마진 잔고는 월간·1개월 지연) | 검증 불가 → 미반영 |
| 외국인 수급: 60거래일 순매수 / 코스피 시총 (ECOS 802Y001) | 2003~ | 단독 AUC 0.61/0.60(한국)이나 위험 점수에 섞으면 표본 내 AUC 하락 → 매크로 패널 **참고 지표로만 표시** |
| CFTC 선물 포지션(TFF): 기관·헤지펀드 S&P500/나스닥100 E-mini 순매수 (골드만 PB의 무료 대체) | 2006~ 주간 | 표본 내·외 방향이 뒤집힘(기관 과열 AUC 0.64→0.38). 위험 점수에 섞어도 3개 시장 모두 개선되는 조합 없음. '기관 헤지 = 반등 여력'도 2006~12만 맞고 2013~ 미국은 반대 → 기각 |
| 고객예탁금, 미국 개인 순매수, 골드만 PB 포지셔닝 | 예탁금은 ECOS·무료 API 없음, 나머지는 무료 데이터 없음 | 검증 불가 → 미반영 |

위험 점수 AUC (표본 내 / 표본 외), 가중치 0.20 (기존 요소 ×0.8):

| 시장 | 기존 | **시장 폭 추가** |
|---|---|---|
| 미국 | 0.649 / 0.719 | **0.667 / 0.738** |
| 미국(기술) | 0.612 / 0.631 | **0.639 / 0.667** |
| 한국 | 0.605 / 0.545 | **0.654 / 0.569** |

- 가중치 0.10~0.25 모두 비슷하게 개선돼(단조 증가, 큰 차이 없음) 중간값 0.20을 썼다.
- 백테스트: 미국 샤프 0.41→0.42·MDD −42.2%→−41.5%·회전율 81%→76%, 한국 연 9.0%→9.2%·샤프 0.41→0.42,
  미국(기술)은 0.47→0.46·MDD −72.3%→−72.6%로 거의 같다. 블록 부트스트랩의 '고정 비중보다 샤프가 높을 확률'은 미국 69%→77%, 한국 83%→88%.
- 배분 공식에서 위험이 깎을 수 있는 폭이 최대 20%p라, 예측력이 좋아져도 수익 변화는 작다. 개선 효과는 주로 '위험 점수가 경고하는 시점의 정확도'.

## 견고성 검증 (`python -m beta_model.validation`)

| 검증 | 방법 | 결과 |
|---|---|---|
| 다른 나라 지수 | 파라미터를 바꾸지 않고 일본·독일·영국·홍콩·대만에 적용 | 7개 시장 **모두** 고정 비중보다 최대낙폭이 작음. 샤프는 6곳에서 같거나 높음(영국만 −0.02) |
| 롤링 워크포워드 | 5년마다 그 이전 데이터만으로 24개 조합 중 선택 → 다음 5년 적용 | 5번 중 4번 현재 설정 선택. 이어 붙인 결과도 고정 비중보다 낙폭 작고 샤프 높음 |

| 비용·지연 | 10/30/50bp, 집행 +1/+2일 | 50bp에서도 샤프 0.39, 낙폭 우위 유지 |
| 가상 충격 | 10거래일 시나리오(완만한 조정·금리 쇼크·원화 급락·2008형·2020형)를 실제 엔진에 통과 | 대시보드 '스트레스 시나리오' — 최악에서도 60% 하한 |

## 정확도 점검 (2026-10)

**1. 시장별 기준일 · 실전 기록 보존** (적용됨)
- 공통 달력(미·한 거래일 합집합)의 마지막 날이 다른 나라 거래일이면, 그 시장 값은 전일 ffill이다.
  이전에는 그 날짜로 기준일을 잡아 16:30 KST 실행에서 '전일 미국 데이터로 계산한 오늘 미국 신호'가 알림·기록됐다.
  → `scores()`가 시장 지수에 실제 종가가 있는 마지막 날에서 끝난다 (`MarketData.trade_dates`). 과거 구간 백테스트 값은 바뀌지 않는다.
- 같은 기준일 재계산(예: 16:30 한국 신호 → 다음날 07:30 미국 종가 반영)이 기록을 덮어써 '실제로 낸 신호'가 사라졌다.
  → `first_*` 열에 최초(알림 시점) 값을 보존, 재계산으로 매매·국면·다음날 비중(2%p 이상)이 바뀌면 **정정 알림**, 대시보드에 '정정' 표시.
- 실전 성과(`live_payload`)의 시차를 백테스트와 같게: t일 신호 → t+1일 종가 집행 → t+2일 수익.

**2. VKOSPI proxy** (옵션 추가, 기본값 유지)
- 실제 VKOSPI가 없으면 변동성 지수 요소(0.24)가 KOSPI200 실현변동성×1.15라 실현변동성 요소(0.12)와 사실상 같은 신호다.
- `RiskParams.vol_proxy_mode`: `"keep"`(현행) / `"drop"`(proxy인 날 변동성 지수 요소 제외·재정규화).
  기존 한국 검증이 모두 keep 기준이라 기본값은 유지 → `python -m beta_model.experiments vol-proxy` 결과로 결정. 근본 해결은 KRX 인증키.

**3. 장기 추세 요소** (실험 코드, 기본 꺼짐)
- 현재 추세 요소는 가장 긴 것이 120일선·3개월 ROC·52주 낙폭. 12-1개월 모멘텀 / 200일선 이격도를 `TrendParams.w_long`으로 추가할 수 있다.
- `python -m beta_model.experiments long-trend`: 12개 조합 + 기준선을 같은 기간으로 잘라 비교,
  표본 내 선택(샤프 최고치 0.01 이내 중 회전율 최저) → 표본 외·미국(기술) 확인 → 채택/기각 권고, 추세 IC·위험 AUC 함께 출력.

## 한국 데이터 인증키 (선택)

키가 없어도 동작하지만, 넣으면 한국 위험 점수가 실제 데이터로 바뀐다.

| 키 | 발급처 | 용도 |
|---|---|---|
| `ECOS_API_KEY` | [한국은행 ECOS Open API](https://ecos.bok.or.kr/api/) → 인증키 신청 (즉시) | 회사채 AA− 3년 − 국고채 3년 (국내 신용 스프레드), CD 91일 (원화 현금 수익률) |
| `KRX_API_KEY` | [KRX Open API](https://openapi.krx.co.kr) → 인증키 신청 + **'파생상품지수 시세정보' 이용신청** (승인 필요) | 실제 VKOSPI (2010~), 그 이전은 실제값 비율로 보정한 proxy |

- 로컬: 프로젝트 루트 `.env` 파일에 `ECOS_API_KEY=...`, `KRX_API_KEY=...` (git 제외됨)
- GitHub Actions: `gh secret set ECOS_API_KEY` / `gh secret set KRX_API_KEY` (값은 프롬프트로 입력)
- 점검: `python -m beta_model.kr_sources --check`
- VKOSPI 최초 백필(약 4,000회 호출, 수 분): `python -m beta_model.kr_sources --update-vkospi` → `data/vkospi.csv` 커밋
